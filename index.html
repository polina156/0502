Изучаем Flexbox

Простая страница для студентов, которые только начинают изучать Flexbox.

display: flex

Превращает элемент в флекс-контейнер. Его дочерние элементы становятся флекс-элементами.

display: flex;

justify-content

Управляет расположением элементов по главной оси.

justify-content: center;

align-items

Управляет расположением элементов по поперечной оси.

align-items: center;
